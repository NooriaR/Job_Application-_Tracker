## Projektbeskrivning
Projektet går ut på att bygga ett program som hjälper användaren att hålla koll på sina jobbansökningar.
Programmet registrerar nya jobb, uppdatera status, filtrera med LINQ, visa statistik och sortera data.

# Hur man kör programmet
Man börjar med att clona ner projektet, öppna med exempelvis Visual studio. Tryck sedan på att köra programmet, följ sedan det som kommer upp i terminalen.
